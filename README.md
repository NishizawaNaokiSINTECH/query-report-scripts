# 検索クエリ取得スクリプト

Google広告とLINEヤフー広告（検索広告）の検索クエリ実績を、毎日スプレッドシートへ書き出す広告スクリプトです。除外キーワードの判断に使うローデータを、手でダウンロードせずに揃えられます。

| ファイル | 貼る場所 |
|---|---|
| `google_ads_query.js` | Google広告のスクリプト |
| `yahoo_ads_query.js` | LINEヤフー広告のスクリプト（検索広告アカウント） |

## 出力されるもの

1本につき2タブを書き出します。毎日どちらも取り直して全面置換します。

| タブ | 期間 |
|---|---|
| 前月タブ（初期値 `検索クエリ_前月_G` / `_Y`） | 前月1日〜前月末日 |
| 当月タブ（初期値 `検索クエリ_当月_G` / `_Y`） | 当月1日〜実行日の前日 |

前月分も毎日取り直すのは、月が閉じた後もCVが遅れて計上されるためです。

列: クエリ / マッチタイプ / キャンペーン / 広告グループ / キーワードID / キーワード / 表示回数 / クリック / CTR / CPC / COST / CV / CVR / CPA

- 並び順: CV降順 → COST降順
- 1行目: 集計期間、fee係数、出力日時の注記
- Google版は検索キャンペーンのみを対象にします（`SEARCH_ONLY: true`）。Yahoo版は検索広告（YSA）のみを対象にし、ディスプレイ（YDA）は取れません

## 準備

1. 書き出し先のスプレッドシートを作る（既存の日販シートでも可）
2. URLの `/d/` と `/edit` の間の文字列をコピーする。これがシートIDです
   `https://docs.google.com/spreadsheets/d/【ここ】/edit`
3. スクリプトを実行するGoogleアカウント（広告管理画面にログインしているアカウント）が、そのシートの編集権限を持っていることを確認する

## Google広告への設定

1. 対象アカウントの管理画面で「ツール」→「一括操作」→「スクリプト」を開く
2. 「＋」で新しいスクリプトを作り、`google_ads_query.js` の中身を全部貼り付ける
3. 冒頭の `CONFIG` を埋める（下の「設定項目」参照）
4. 「承認」でスプレッドシートへのアクセスを許可する
5. 「プレビュー」で実行し、ログに「完了」と出てシートに2タブができることを確認する
6. 保存して、頻度を「毎日」、時刻を 11:00 前後に設定する

## LINEヤフー広告への設定

1. 対象の検索広告アカウントでスクリプトの管理画面を開き、新しいスクリプトを作る
2. `yahoo_ads_query.js` の中身を全部貼り付け、`CONFIG` を埋める
3. スプレッドシートの連携（承認）を行い、実行してシートを確認する
4. 毎日実行のスケジュールを 13:00 前後に設定する

Google版と同じスプレッドシートに書く場合は、2本の実行時間帯をずらしてください。同時に書き込むと片方が失敗することがあります。

## 設定項目

| 項目 | 意味 | 入れる値 |
|---|---|---|
| `SHEET_ID` | 書き出し先のシートID | 入力不要。実行時に案件マスタの「出力先SHEET_ID」列の値が入る |
| `TAB_PREV` / `TAB_CUR` | タブ名の頭 | 通常は変えない。後ろに案件マスタの「タブ接尾辞」（例: `_ゴルフ`）が付く。無ければ自動で作られる |
| `MASTER_SHEET_ID` | fee係数を読む案件マスタ | 変えない |
| `FEE` | COST・CPC・CPA に掛ける係数 | 入力不要。実行時に案件マスタの「fee係数」列の値が入る |
| `SEARCH_ONLY`（Google版） | 検索キャンペーンだけに絞るか | 通常は `true` のまま |
| `MATCH_TYPE_FIELD`（Yahoo版） | マッチタイプ列の項目名 | 通常は変えない。空にすると候補を順に試して自動で判定する |

## 注意

- 出力は fee係数を掛けた請求ベースです。別のシートやツールでさらに fee を掛けて加工すると二重掛けになります
- 書き込み中にエラーが出た場合、タブが途中までの状態で残ります。ログに「★ 書き込みが中断しました」と出ていたら、手動で再実行してください

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 「出力先SHEET_ID が空です」 | 案件マスタの該当行に出力先のシートIDが入っていない |
| 「取得0件のためタブは更新しません」 | その期間に検索広告の配信がない。配信があるのに出る場合は、アカウントを取り違えていないか確認する。0件の日は前回のデータを消さずに残す仕様 |
| 毎月1日に当月タブが空になる | 仕様。1日は「当月1日〜前日」が成立しないため。前日（前月末日）までの分は前月タブにある |
| Yahoo版で「全候補でレポートを取得できませんでした」 | 直前のログのエラーを確認する。項目名の問題なら、判明した名前を `MATCH_TYPE_FIELD` に入れる |
| シートへのアクセスエラー | スクリプトを承認したアカウントに、書き出し先シートの編集権限か案件マスタの閲覧権限がない |
| 「案件マスタに行がありません」 | マスタに対象アカウントの行が無いか、媒体名・アカウントIDが違う。マスタに追加・修正する |
| 「同一アカウントの行が2件あります」 | マスタに同じ媒体・アカウントIDの行が重複している。1行にまとめる |
| 「fee係数が読めないか範囲外です」 | マスタのfee係数が空欄、または 120 のように % なしで入っている。`120%` か `1.2` にする |
